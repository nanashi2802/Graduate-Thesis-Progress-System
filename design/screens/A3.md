# A3 · Consultations

**Route:** `/adviser/consultations` · **Role:** Adviser · **Density:** comfortable · **FRs:** FR-SCH-05, FR-SCH-06

## Job
Keep each advisee's consultation log (TDW 03) and send the signed form.

## Regions
| # | Region | Pattern | Content |
| :---- | :---- | :---- | :---- |
| 1 | Picker | Name chips | "All advisees" first, then one chip for each advisee |
| 2 | Overview ("All advisees") | Queue table | Each advisee: phase, entries to confirm, last and next meeting, TDW 03 state. A click opens that Student's log. |
| 3 | Phase tabs (one Student) | Tabs | Current phase open. Earlier phases read only. Later phases locked. |
| 4 | Log | Consultation log | The columns of TDW 03: date and time, place or platform, topics, the Adviser's confirmation |
| 5 | Form card | Card (1 of 3) | TDW 03: document stamp, "Download form", "Upload scan" |

## States
| State | What shows |
| :---- | :---- |
| One advisee | The picker and the overview do not show. The page opens on that Student's log. |
| First day | Log: "No consultations yet. Entries appear here after each booked consultation." |
| Before date confirmation | The form card says the signed TDW 03 is needed before the Coordinator confirms the defense date |
