# C7 · Clearance

**Route:** `/coordinator/clearance` · **Role:** Coordinator · **Density:** compact · **FRs:** FR-CLR-01 to FR-CLR-04, FR-WFL-07, FR-WFL-10

## Job
Check each clearance item and record CLEARED.

## Regions
| # | Region | Pattern | Content |
| :---- | :---- | :---- | :---- |
| 1 | Student list | Queue table | Students in clearance: Student, items done, age, Action ("Check item") |
| 2 | Items (one Student) | Task list | IPMO, RPO, copyright (outside chips with selectors), Gate 2 tracker, final copy, evidence. Each evidence row: Verify or Return (Return composer). |
| 3 | Close | Docket action | "Record cleared" (maroon) |

## States
| State | What shows |
| :---- | :---- |
| Not ready | "Record cleared" is disabled: "A clearance item is incomplete." |
| Cleared | `achieved` pill |
| First day | "No Students in clearance. Students appear here at Milestone 3." |

## Rules
- CLEARED needs every item verified.
