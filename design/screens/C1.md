# C1 · Overview

**Route:** `/coordinator/dashboard` · **Role:** Coordinator · **Density:** compact · **FRs:** FR-TRK-04, FR-TRK-05, FR-TRK-06, FR-RPT-03
**Mockup:** Coordinator mockups v5 (locked)

## Job
Show every queue that waits for the Coordinator, and let them open the oldest item.

## Regions
| # | Region | Pattern | Content |
| :---- | :---- | :---- | :---- |
| 1 | KPI strip | KPI strip | Six counts: All waiting, Check scans, Confirm dates, Appoint committees, Close defenses, Check clearance. Each cell: the count (`kpi`, 36 px mono) and the oldest age beside it ("4 · 6d", amber when late), the glyph (30 px) in the top-right corner, the label below. A click filters the queue. |
| 2 | Action queue | Queue table, grouped | Columns: Student, Form, Request, Milestone, Waiting, Action. Group rows by queue, each with its glyph and count. |
| 3 | Students | Queue table | Columns: Student (full title in a tooltip), Adviser, Milestone, Status, Target, Flags. Filter chips: Active, Milestone, Status, Flags. "Add a Student". |

## States
| State | What shows |
| :---- | :---- |
| First day | All counts are 0 (muted). The queue is an empty state that names the first step, "Add faculty", as the one maroon action. |
| Working | As above |

## Rules
- Row actions: fixed 132 × 32 px, one or two words ("Check scan", "Confirm date", "Appoint", "Open defense", "Check item").
- 48 px rows, 16 px cell padding, fixed column widths.
- Flag reasons and full thesis titles go in tooltips (G5). No helper lines (G4).
- Flags never block (BR-17).
