# C10 · Audit

**Route:** `/coordinator/audit` · **Role:** Coordinator · **Density:** compact · **FRs:** FR-RPT-01, FR-RPT-02, FR-NTF-07

## Job
Find any recorded action and export the audit log.

## Regions
| # | Region | Pattern | Content |
| :---- | :---- | :---- | :---- |
| 1 | Filters | Filter chips | Student, actor, action, date |
| 2 | Results | Queue table | Time (mono), actor, action, Student, detail (tooltip for long text) |
| 3 | Export | Secondary button | "Export CSV" with the `export` glyph |

## States
| State | What shows |
| :---- | :---- |
| No results | "No records match these filters." |

## Rules
- Read only. Audit records are never changed or deleted (BR-19).
- Includes email events (FR-NTF-07).
