# S1 · Dashboard

**Route:** `/student/dashboard` · **Role:** Student · **Density:** comfortable · **FRs:** FR-TRK-01, FR-TRK-05, FR-WFL-12

## Job
Show where the thesis stands and the one next step.

## Regions
| # | Region | Pattern | Content |
| :---- | :---- | :---- | :---- |
| 1 | Identity line | Identity line | Thesis title (serif, `display`) and degree level |
| 2 | Docket | Docket, stepper | "Step x of 4", the four-node stepper, the status pill, the blocker in one line, one primary action, and a direct "Download form" link when the step needs a form |
| 3 | Key dates | Card (1 of 3) | The next dates: defense date, room or link, printed-copy due date (BR-09), target dates. It holds the defense details after date confirmation. |
| 4 | This milestone | Task list | The items of the current milestone only, each with its state and its reason if it blocks |
| 5 | Adviser and comments | Ruled section | The Adviser's name, the **total** number of open comments (all reviewers, not split by reviewer), and the next consultation |

## States
| State | What shows |
| :---- | :---- |
| First day | No manuscript, no dates, no consultation. The Docket names the first step (upload the first manuscript version) and shows "See the whole process", a link to PROCESS. Key dates: "No dates yet. Your defense date appears here after the Coordinator confirms it." Comments: "No comments yet." |
| Working | As above, with data |
| Blocked by an outside office | The outside status (Ethics, IPMO, RPO) shows as the Docket blocker, and only when it blocks the step |
| Achieved | The stepper node turns gold. The status pill uses `achieved`. |
| Residency flag | A flag line under the Docket. Information only (BR-17). |

## Rules
- Show only items of the Student's degree level and current milestone (G2).
- No outside-offices section. An outside status shows only as a blocker.
- One maroon button on the page: the Docket action.
