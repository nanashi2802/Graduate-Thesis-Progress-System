# A2 · Review and gates

**Route:** `/adviser/pr/[prId]` · **Role:** Adviser · **Density:** comfortable · **FRs:** FR-REV-04, FR-WFL-03, FR-WFL-04, FR-WFL-05, FR-WFL-07

## Job
Review the manuscript, comment, and pass the Adviser's gate or Return the work.

## Regions
| # | Region | Pattern | Content |
| :---- | :---- | :---- | :---- |
| 1 | Identity line | Identity line | Thesis title, Student, degree level, milestone, committee |
| 2 | Gate box | Gate box (Primer) | Each gate condition with a pass or fail glyph. Then the gate button ("Endorse (Gate 1a)"). Return beside it. |
| 3 | Commit selector | Commit selector | As on S2 |
| 4 | Workspace | Workspace: PDF viewer + thread feed | The Adviser's own open threads have an amber edge, because they block the gate. Composer at the foot of the feed. |
| 5 | Revision check | Checkbox row | Milestone 3, Gate 1b only: "Pre-Final revisions accepted" |

## States
| State | What shows |
| :---- | :---- |
| No Ready commit | The gate box says "Waiting for the Student to mark a version Ready." The gate button is disabled with that reason. |
| Conditions not met | The gate button is disabled. The failing check names the reason from SITEMAP §9 ("You have open threads. Resolve them first."). |
| All conditions met | The gate button is enabled (maroon). It opens the gate dialog. |
| Locked | The lock banner (BR-07). Commenting rules follow the milestone. |

## Rules
- The Adviser resolves only their own threads (BR-05).
- Return is always available. It opens the Return dialog with a required reason (FR-WFL-05). It is an outline button, never solid red (F3).
- Gate 1a in Milestone 2 also needs IPMO PASSED.
- A thread may carry an optional page number (FR-REV-04). The composer has an optional "Page" field.
