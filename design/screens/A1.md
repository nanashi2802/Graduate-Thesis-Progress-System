# A1 · Advisees

**Route:** `/adviser/dashboard` · **Role:** Adviser · **Density:** comfortable · **FRs:** FR-TRK-02, FR-TRK-06, FR-REV-09, FR-WFL-11

## Job
Show what waits for the Adviser, oldest first, and where each advisee stands.

## Regions
| # | Region | Pattern | Content |
| :---- | :---- | :---- | :---- |
| 1 | Action queue | Queue table | Oldest request on top. Each row: Student, the request in plain words, days waiting, one action. Gate actions show their gate tag. Items: Gate 1a, Gate 1b, Gate 2, consultation log entries, TDW 03, data-gathering approval. |
| 2 | Advisees | Ruled list | One row for each advisee: the full four-node stepper, the status pill, and two facts. Facts: open comments and the next consultation. After a defense date is set, the date replaces the open-comments fact. |

## States
| State | What shows |
| :---- | :---- |
| First day | Queue: "No requests are waiting. Requests appear here when an advisee marks a version Ready." Advisees: "No advisees yet. The Coordinator assigns advisees when they make a Student account." |
| Late item | The age turns amber (`pending`), never red |
| Advisee-limit flag | Only if the C8 parameter is on (FR-TRK-06). A flag line, never a block. |

## Rules
- Approve data gathering after CERTIFIED (FR-WFL-11).
- Pacing flags are information only (BR-17).
- Gold marks completed or certified milestones on the steppers.
