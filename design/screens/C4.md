# C4 · Documents

**Route:** `/coordinator/documents` · **Role:** Coordinator · **Density:** compact · **FRs:** FR-DOC-06 to FR-DOC-08, FR-WFL-10
**Mockup:** Coordinator mockups v5 (locked)

## Job
Check each uploaded scan against the paper, then Verify it or Return it.

## Regions
| # | Region | Pattern | Content |
| :---- | :---- | :---- | :---- |
| 1 | Tabs | Tabs | Scans to check (count), Outside offices, All documents |
| 2 | List (300 px) | Inbox list | One row for each scan: Student, age (amber when late), document stamp, milestone. Oldest first. |
| 3 | Scan | PDF viewer | The scan. The bar holds only the file name and zoom. |
| 4 | Record (300 px) | Inbox record | Document stamp and name, Student and milestone. A 2-step state bar ("Scan uploaded" then "Verified" or "Returned"). Two full-width actions: Verify (maroon) and Return. File details always shown below: uploaded, by, SHA-256. |
| 5 | Outside offices tab | Queue table | Student, milestone, Ethics, IPMO, RPO, copyright. Each office has a status selector when it is current. A blank cell means "not yet". |

## States
| State | What shows |
| :---- | :---- |
| Checking | The two actions |
| Verify | A dialog: "Verify TDW 12 for Dino Aquino? This locks the document." Verify, Cancel. |
| Writing a Return | The actions are replaced by the Return composer: "Reason for return", a free-text field with one placeholder example. "Cancel" and "Send return". "Send return" is disabled with "Write a reason first" until the field has text. |
| Returned | "Returned to <Student>", the reason in quotes, the time. State bar: "Next: new scan from the Student". |
| Verified | "Verified", the time, "locked" |
| First day | "No scans are waiting. New scans appear here when a Student uploads one." |

## Rules
- Verify or Return only. No checklist, no Flag action, no "Physical received" step. (FR-DOC-02, FR-DOC-06, FR-DOC-07)
- The Coordinator decides if the paper is final. The system cannot read signatures.
- A Return reason is compliance or eligibility only (BR-13). Free text, no presets.
- Verify is permanent (BR-19).
