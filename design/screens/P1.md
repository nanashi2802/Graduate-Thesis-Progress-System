# P1 · Assignments

**Route:** `/panel/dashboard` · **Role:** Panel Member · **Density:** comfortable · **FRs:** FR-TRK-03, FR-REV-09

## Job
Show the Panel Member's assignments and what waits for them.

## Regions
Same structure as A1 (`A1.md`): action queue first, then one row for each assigned Student.

| Difference from A1 | Detail |
| :---- | :---- |
| Row facts | Milestone, designation (Lead Panel Member or Panel Chair, if any), access status |
| Queue items | Gate 1b, Gate 2, reviews, Defense Day |
| Defense schedule | The next defense date on each row once set |

## States
| State | What shows |
| :---- | :---- |
| Access locked | The row shows a `locked` pill: "Locked until the appointment form and your NDA are recorded." (BR-08). The manuscript link is disabled with that reason. |
| Access ended | A `locked` pill after the event in BR-21 |
| First day | "No assignments yet. The Coordinator appoints Panel Members after Gate 1a." |
