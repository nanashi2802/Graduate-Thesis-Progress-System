# S3 · Documents

**Route:** `/student/documents` · **Role:** Student · **Density:** comfortable · **FRs:** FR-DOC-01 to FR-DOC-05, FR-DOC-09, FR-DOC-11

## Job
Show the forms of the current milestone and collect the signed scans.

## Regions
| # | Region | Pattern | Content |
| :---- | :---- | :---- | :---- |
| 1 | Identity line | Identity line | Thesis title, degree level, milestone |
| 2 | This milestone | Task list | One row for each form of the current milestone: document stamp (form number + state), name, "Download form", "Upload scan". Read-only rows for records the Student does not upload (Minutes, sheets, Certification). |
| 3 | Completed milestones | Collapsed group | Earlier milestones, read only |
| 4 | Advising forms · optional | Collapsed group | TDW 01, TDW 04, TDW 02 with "Upload copy". Optional, never verified, never blocking. (FR-DOC-12) |
| 5 | History tab | Tab | The upload and state history of each document |

## States
| State | What shows |
| :---- | :---- |
| First day | Every row shows "Not started" and "Download form". The forms are visible from day one. |
| Scan uploaded | The stamp says "Scan uploaded". "Upload scan" is disabled with "Locked. A replacement needs a Return." (BR-19) |
| Returned | The stamp says "Returned". Under the row, the Coordinator's reason, word for word. The action becomes "Upload new scan". |
| Verified | The stamp says "Verified" (`done` tone). |

## Rules
- Show only documents of the current milestone and degree level (G2).
- A scan locks on upload. A replacement needs a Return (FR-DOC-03, BR-19).
- No forms-guide tab. The forms guide is on PROCESS.
- Phones: read only for now (D-12).
- The document states follow FR-DOC-02: Not started, Prepared, Scan uploaded, Locked as submitted, Verified, Returned.
