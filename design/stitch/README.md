# Google Stitch screens: prototype only

**Status:** Prototype only. This folder is not a reference for the design, the process or the system behavior.

The initial screens in this folder came from Google Stitch. They show an early idea of the app. They do not show an approved design.

## Do not use these files as a source

| Do not | Use instead |
| :---- | :---- |
| Copy colors, fonts, layout or components from these screens | `DESIGN.md` |
| Take routes, screens or access rules from these screens | `spec/SITEMAP.md` and the Operational Flow, DFD and Sitemap v3.1 |
| Take process steps, form use or rules from these screens | The Unified Thesis Process v1.1 and the Functional Requirements v1.1 |
| Take sample names, statuses or labels as real data | Fake seed data that follows the documents above |

If a screen here disagrees with a document, the document wins. Do not correct the document to match the screen.
